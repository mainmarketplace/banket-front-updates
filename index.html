■ Банкетный фронт · Кафе «Любава»

Установка на компьютер банкетного зала. Ничего заранее ставить не нужно.

Скачать установщик
  1. Скачанный файл «Установить банкетный фронт.bat» запустите двойным кликом (если браузер спросит — «Сохранить», Windows — «Подробнее → Выполнить в любом случае»).
  2. Чёрное окно 1–2 минуты скачает Python и программу и напишет DONE.
  3. На рабочем столе появится ярлык «Банкетный фронт» — программа уже запущена и будет запускаться сама при включении компьютера.
  4. При первом входе выберите свой зал, дальше — вход по PIN-коду сотрудника.
Обновления программа получает сама. Вопросы — Алексею Хозяйкину.
